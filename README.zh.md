# SetupKit

[English](README.md) · [Español](README.es.md) · [Português (Brasil)](README.pt.md) · [日本語](README.ja.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Русский](README.ru.md) · 简体中文

帮助 AI 了解你的工作方式。这份免费指南帮助你在自己的 AI 对话中制定工作规则，并着手处理一项实际任务。

## 如何开始

1. 复制[启动提示词](prompts/zh.txt)。
2. 粘贴到自己的 AI 对话中并发送。请明确要求使用简体中文交流。
3. 回答与你有关的问题，再选择一项任务一起完成。

可以直接在当前对话中开始。告诉助手你使用什么工具，以及如何使用。如果任务需要额外的访问权限，请先确认当前对话能做什么。你可以手动继续、暂时跳过这一步，或选择其他工作模式。仅仅安装应用，并不保证能获得所需的工具。

## 当前版本

[完整指南](COMPLETE.md)的版本为 `0.19`，更新日期为 `2026-10-19`。助手应提出相关问题，解释提问的原因，并使用你已经提供的答案。

如果无法读取来源，请按照[提供完整文本的步骤](docs/getting-started.md#if-the-guide-cannot-be-read)操作。缺失的内容应向你索取，不能凭空编造。[兼容性与限制](docs/compatibility.md)说明了哪些内容已经验证，哪些尚未验证。这些参考文档和作为依据的指南正文均为英文。

## 按需整理工作空间和个人背景

如果有帮助，你也可以整理现有工作空间，并将有关自己、目标和工作的已核对信息整理成少量文件。先利用已有材料，例如简历或你选定的项目笔记。由你决定要做哪些改动；问题可以跳过，也可以留待以后回答。

继续工作时，请提供已保存的进度或接续摘要，以便助手复用已确认的回答，并检查与你有关的未完成步骤或新增步骤。保存文件需要你的批准，而且助手必须具备相应的实际访问权限；创建文件本身并不保证自动记忆或同步。

## 按需整理选定的材料

你可以请助手帮忙整理自己选定的文件、链接或笔记。它会建议每份材料属于哪个项目、适合放在哪里，以及哪些内容值得总结，并保留对原始材料的引用。先检查建议，再决定哪些要改、哪些留待以后。只有获得你的同意且具备所需访问权限时，才会保存或移动文件；否则，助手会提供可手动执行的方案。继续工作时，提供检查过的整理记录，让助手重点处理新增、已更改或尚未完成的项目。

## 技能

- [Clarify](skills/setupkit-clarify/README.zh.md): 在开始工作前，通过有针对性的问题明确任务。
- [Fact Check](skills/setupkit-fact-check/README.zh.md): 在发布前，核查事实性陈述、相关证据和媒体素材的相关要求。

如需安装两个技能，请先阅读[通用安装指南](INSTALL.zh.md)并检查现有技能文件夹。首次尝试请使用新的空白测试项目。

```bash
npx skills add etsarkov/setupkit-ai \
  --skill setupkit-clarify \
  --skill setupkit-fact-check
```

选择助手和当前项目范围，确认前检查目标路径。npx 会运行安装程序。兼容性限制和单个技能的安装说明见[技能概览](skills/README.zh.md)。

## 工作内容由你掌握

无需注册 SetupKit 账号。SetupKit 不会收到你向助手提供的回答。你所用助手的费用、权限和数据处理规则仍然适用。要求起草内容，并不等于允许发送、发布、安装、连接账号或修改文件。

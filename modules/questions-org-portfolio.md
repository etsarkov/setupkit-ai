### ORG-13 — ORG

Question: Which projects or areas of work would you like to keep track of together? A name and a short description of each are enough.

Why: These might be client work, studies and a personal project. Start with the ones that matter now; there is no need to list everything.

Effect / if deferred: This defines what belongs in the shared overview and keeps unrelated work out. If you have just one project or do not want an overview, skip PROJECTS.md. If you are unsure, begin with the task already selected.

Activate / reuse: Several relevant directions exist, the person wants a shared overview, and the selected list is missing or incomplete. No full inventory is requested. Reuse confirmed applicable answers and selected sources first. Relevant IDs: ORG-01, ORG-02, ORG-03, ORG-04, GOAL-06. Reuse named actual work and known purposes from any of these answers; do not ask again to populate a portfolio template.

### ORG-14 — ORG

Question: Where does [chosen project] stand now: still an idea, underway, on hold, finished, or something else?

Why: Use your own words if none of these fits. This avoids treating every project as equally active.

Effect / if deferred: The overview will show where attention is needed and what is currently paused or finished. If the stage is unknown, label it unknown and leave it out of confident scheduling decisions. You can clarify it when the project becomes relevant.

Activate / reuse: ORG-13's overview is chosen and an actual selected project's stage is not already current/confirmed. Ask only about missing projects, possibly one at a time. Reuse confirmed applicable answers and selected sources first. Relevant IDs: ORG-13, NOW-01. Reuse actual current status; folder labels and a future target are not evidence of the present stage.

### ORG-15 — ORG

Question: Are these projects connected—for example, does one need a result from another before it can move forward?

Why: They may also share useful materials or the same client. 'They are independent' is a complete answer.

Effect / if deferred: This helps avoid duplicated work and suggests a sensible order where a dependency actually exists. If you are unsure, leave connections unknown and plan each project separately for now; do not claim that they are independent.

Activate / reuse: A multiple-project overview is chosen and relationships could change the work order or reuse of material; no confirmed relationship/independence statement exists. Reuse confirmed applicable answers and selected sources first. Relevant IDs: ORG-13, ORG-14, GOAL-07. Reuse explicitly stated dependencies or shared constraints; similar names and shared keywords are insufficient.

### Review the clear items together; leave uncertainty visible

Show a compact table in the person's language: material; what it appears to be and its project/task; proposed action and exact destination where relevant; short reason; anything unresolved. Normally show up to ten rows at a time for readability and state the remaining count. Do not silently drop the rest, treat ten as a question quota or treat a large selection as permission for an unlimited operation loop.

Use concrete, easy choices only for material gaps, following the existing question/why/effect-and-fallback format. For example: “Does this interview belong to Project A, or should it stay unassigned? Why: That determines where you will find it later. If later: I will leave it where it is and continue with the clear items.” Or: “Is this presentation ready to use, or still being edited? Why: This separates finished results from working files. If later: I will keep it with working material.” Reuse an answer already known; do not rephrase it into another required question. Answer, defer, not applicable and decline remain valid, and only the dependent action pauses.

A person can accept selected clear rows together, correct a destination, request only a summary, keep an item in place or defer it. Before a required action approval, show the exact selected paths, content/delta, operations and effects. A move makes the item unavailable at its old location: say so, show known reference effects within the selected scope and include any proposed reference edits. Do not scan the whole workspace for all possible backlinks. Binding approval to the current proposal and selected rows avoids asking the same permission once per file. Reuse a still-valid exact current authorization; a broad request to organize or an old module opt-in is not approval of unseen moves, new destinations or changed content.

Placement review, confirmation of a statement, and permission to write are distinct. To promote a source into reusable knowledge or a context/decision record: show the exact proposed statement, source, uncertainty and intended file delta; obtain the required meaning review and action permission; then verify any actual save. A note saying “we decided” or a general “put these in Project A” does not establish a confirmed personal decision. Do not turn an unanswered confirmation into a fact to fill a template.

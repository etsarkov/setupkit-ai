# Установка скиллов SetupKit

[English](INSTALL.md) · [Español](INSTALL.es.md) · [Português (Brasil)](INSTALL.pt.md) · [日本語](INSTALL.ja.md) · [Deutsch](INSTALL.de.md) · [Français](INSTALL.fr.md) · Русский · [简体中文](INSTALL.zh.md)

Выберите [Clarify](skills/setupkit-clarify/README.ru.md), чтобы превратить неясный запрос в рабочее задание, или [Fact Check](skills/setupkit-fact-check/README.ru.md), чтобы проверить утверждения и доказательства. Перед установкой прочитайте выбранный SKILL.md.

Эта инструкция описывает установку в проект. Для первой пробы используйте новый пустой тестовый проект. Подключение аккаунта, API-ключ и платный API моделей в эти инструкции не входят. Стоимость и права выбранного ассистента продолжают действовать.

## Перед установкой

1. Выберите один или оба скилла и ассистента, которым будете пользоваться.
2. Проверьте целевые папки ассистента и общие папки проекта `.agents/skills/setupkit-clarify` и `.agents/skills/setupkit-fact-check`. Если одноимённая папка уже существует, остановитесь и отдельно решите вопрос обновления. Предупреждения о перезаписи могут не охватывать все общие пути.
3. Выберите установку в проект. Несколько ассистентов используют `.agents/skills`; другие ассистенты проекта тоже могут обнаружить размещённые там файлы.

## Skills CLI

[Документация разработчиков Skills CLI](https://github.com/vercel-labs/skills/blob/13e4063a1cf913f5606d57d42ab83a86f5001e04/README.md) перечисляет Codex, Claude Code, Cursor, Gemini CLI, OpenCode, Windsurf и GitHub Copilot. Манифест изученного репозитория требует Node.js 22.20.0 или новее. Используйте среду, которую требует выбранная версия.

Откройте терминал в папке нужного проекта. `npx` загружает и запускает установщик; перед запуском ознакомьтесь с пакетом его разработчиков.

Оба скилла:

```bash
npx skills add etsarkov/setupkit-ai \
  --skill setupkit-clarify \
  --skill setupkit-fact-check
```

Только Clarify:

```bash
npx skills add etsarkov/setupkit-ai --skill setupkit-clarify
```

Только Fact Check:

```bash
npx skills add etsarkov/setupkit-ai --skill setupkit-fact-check
```

Выберите ассистента и установку в проект. Перед подтверждением проверьте все заранее выбранные параметры, пути и итоговый список. Отмените установку, если существующий скилл будет заменён без отдельного решения об обновлении. В этих примерах подтверждение не отключается.

Чтобы указать целевого ассистента, добавьте его идентификатор, например `--agent cursor`, `--agent gemini-cli` или `--agent opencode`. Другие идентификаторы и пути перечислены в [таблице разработчиков](https://github.com/vercel-labs/skills/blob/13e4063a1cf913f5606d57d42ab83a86f5001e04/README.md#supported-agents).

Примеры проектных путей из изученного кода установщика:

| Цель установщика | Папка проекта |
|---|---|
| Codex, Cursor, Gemini CLI, OpenCode, GitHub Copilot | `.agents/skills/` |
| Claude Code | `.claude/skills/` |
| Windsurf | `.windsurf/skills/` |

Таблица описывает размещение файлов установщиком, а не результаты тестов SetupKit в каждом ассистенте. Команды выше не закрепляют версию установщика: последующая версия может отличаться от изученного исходного кода.

## Альтернатива для Codex

Если в вашем Codex доступен skill-installer, откройте нужный проект и отправьте:

```text
$skill-installer Установи SetupKit Clarify и SetupKit Fact Check из:
https://github.com/etsarkov/setupkit-ai/tree/main/skills/setupkit-clarify
https://github.com/etsarkov/setupkit-ai/tree/main/skills/setupkit-fact-check
Установи только в этот проект. Существующие скиллы не меняй. Если установка в проект недоступна, объясни ограничение без изменения файлов.
```

Для одного скилла оставьте только его название и URL. Запрос выражает желаемый охват; до разрешения изменений проверьте фактическую папку установки. Если установщик предлагает только установку для всего пользователя, остановитесь и выберите подходящий способ для проекта. См. [официальную инструкцию Codex](https://learn.chatgpt.com/docs/build-skills).

## Ручная установка и Claude Code

Скачайте архив репозитория с GitHub и распакуйте его вне папок, в которых ассистент обнаруживает скиллы. Прочитайте выбранные SKILL.md. Скопируйте только нужные папки из `skills/` в проектный каталог, указанный в документации ассистента, сохранив названия и содержимое. Сначала проверьте как целевые, так и общие пути; не заменяйте существующую папку без отдельного решения об обновлении.

Codex, установка в проект:

```text
.agents/skills/setupkit-clarify/SKILL.md
.agents/skills/setupkit-fact-check/SKILL.md
```

Claude Code, установка в проект:

```text
.claude/skills/setupkit-clarify/SKILL.md
.claude/skills/setupkit-fact-check/SKILL.md
```

Для одного скилла достаточно его папки. Сохраняйте копируемые переводы README и все сведения об авторе и лицензии внутри SKILL.md. В Claude Code после обнаружения скилла начните сообщение с `/setupkit-clarify` или `/setupkit-fact-check`. См. [официальную документацию Claude Code](https://code.claude.com/docs/en/skills).

Для другого ассистента проверьте официальный путь обнаружения и способ вызова. Храните одну копию инструкций каждого скилла; адаптация пути не требует перевода или переписывания SKILL.md.

## Проверка результата

1. Убедитесь в списке скиллов или окне обнаружения, что выбранные идентификаторы появились в рамках проекта. Начните новую задачу или перезапустите ассистента, если этого требует его механизм обнаружения.
2. Попробуйте пример из [Clarify](skills/setupkit-clarify/README.ru.md) или [Fact Check](skills/setupkit-fact-check/README.ru.md). Проверьте, что нужный скилл действительно загрузился.
3. Сопоставьте ответ с назначением примера. Clarify должен спрашивать только о недостающих существенных сведениях. Fact Check должен показывать пробелы в доказательствах и подходящее решение, в том числе BLOCK при необходимости.

## Совместимость и разрешения

Структура файлов и формы команд сверены с сохранённой документацией и исходным кодом разработчиков. Границы тестов конкретных версий приведены ниже; для остальных перечисленных ассистентов эти тесты не подтверждают штатный запуск SetupKit. Наличие цели в установщике не доказывает одинаковое срабатывание, инструменты, доступ к источникам, разрешения или качество проверки.

Для утверждений, которые меняются со временем, Fact Check нужен доступ к актуальным источникам. Если существенных доказательств нет, утверждение остаётся неразрешённым. Пакет не содержит и не устанавливает humanizer; Fact Check может работать без него.

Загрузка, выполнение и разрешения контролируются ассистентом. Скилл или решение PASS не разрешают публикацию, отправку, расходы, установку или подключение аккаунта. Передавайте только материалы, которыми вы вправе делиться с выбранным ассистентом, и ознакомьтесь с его условиями обработки данных.

## Проверенный тестовый режим

18 октября 2026 года проверена установка копированием в новые проекты macOS через npm/npx 11.6.2 и Skills CLI 1.7.2. Оба скилла явно вызваны в Codex 0.163.0-alpha.10.2 (gpt-6.1-sol) и OpenCode 2.0.22 (gpt-5.6-sol) через существующую подписку ChatGPT. Синтетические тесты включали неполное/полное задание и неподтверждённые/корректные утверждения.

В тестовой среде сценарии жизненного цикла npm были отключены.

Проверенная команда копирования для Codex без интерактивных вопросов:

```bash
npx --yes skills@1.7.2 add etsarkov/setupkit-ai --skill setupkit-clarify --skill setupkit-fact-check --agent codex --copy --yes --json
```

Для проверенного варианта OpenCode замените `codex` на `opencode`. Используйте этот режим с пропуском подтверждений только после самостоятельной проверки скиллов, установки в проект и всех целевых папок. В примерах выше подтверждения сохраняются.

Эти тесты не проверяют интерактивные настройки по умолчанию, стандартный режим символических ссылок, глобальную установку, автоматическое срабатывание, проверку актуальных веб-источников или другие версии ассистентов. Качество ответа для любой задачи не гарантируется.

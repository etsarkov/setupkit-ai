# SetupKit

[English](README.md) · [Español](README.es.md) · [Português (Brasil)](README.pt.md) · 日本語 · [Deutsch](README.de.md) · [Français](README.fr.md) · [Русский](README.ru.md) · [简体中文](README.zh.md)

あなたの仕事の進め方をAIに伝えるための無料ガイドです。自分のAIチャットで作業のルールを決め、実際のタスクに取り組む手助けをします。

## はじめ方

1. [開始プロンプト](START_PROMPT.txt)をコピーします。
2. 自分のAIチャットに貼り付けて送信します。日本語で会話するよう伝えてください。
3. 必要な質問に答え、一緒に取り組むタスクを選びます。

今使っているチャットから始められます。使っているツールと、その使い方をアシスタントに伝えてください。追加のアクセスが必要なタスクでは、まずそのチャットで何ができるか確認します。手動で進める、その手順を後回しにする、別の作業環境を選ぶこともできます。アプリをインストールするだけで、必要なツールが使えるとは限りません。

## 現在のバージョン

[ガイド全文](STARTER.md)は `0.17.1` 版、更新日は `2026-10-19` です。アシスタントは、状況に合った質問をし、その理由を説明し、すでに伝えた回答を活用することを求められます。

元のテキストを読み込めない場合は、[全文を渡す手順](docs/getting-started.md#if-the-guide-cannot-be-read)に従ってください。足りない内容は推測で補わず、提供を求める必要があります。[互換性と制限](docs/compatibility.md)では、確認済みの範囲と未確認の範囲を説明しています。これらの参照文書と元のガイドは英語です。

## 必要に応じて作業環境と情報を整理する

必要であれば、今の作業環境を整理し、自分自身や目標、仕事について確認した情報を少数のファイルにまとめることもできます。履歴書や、選んだプロジェクトのメモなど、すでにある資料から始めます。何を変更するかは自分で選べます。質問には答えずに進んだり、後回しにしたりできます。

再開するときは、保存した進捗や引き継ぎ用の要約を渡してください。アシスタントが確認済みの回答を再利用し、未完了の手順や新しく加わった手順のうち、関係するものを確認するためです。ファイルの保存にはあなたの承認と、アシスタントが実際に持つアクセス権限が必要です。ファイルを作るだけで、自動的に記憶されたり同期されたりするわけではありません。

## スキル

- [Clarify](skills/setupkit-clarify/README.ja.md): 作業を始める前に、要点を絞った質問で依頼内容を明確にします。
- [Fact Check](skills/setupkit-fact-check/README.ja.md): 公開前に、主張とその根拠、画像・動画・音声などの素材に関する要件を確認します。

両方をインストールする場合は、まず[共通インストールガイド](INSTALL.ja.md)を読み、既存のスキルフォルダーを確認してください。初回は新しい空のテスト用プロジェクトを使います。

```bash
npx skills add etsarkov/setupkit-ai \
  --skill setupkit-clarify \
  --skill setupkit-fact-check
```

アシスタントとプロジェクト単位の範囲を選び、確定前に配置先を確認します。npxはインストーラーを実行します。互換性の制限と個別のインストール手順は[スキルの概要](skills/README.ja.md)を参照してください。

## 作業内容は自分で管理できます

SetupKitのアカウントは不要です。アシスタントに伝えた回答がSetupKitに送られることはありません。利用するアシスタントの料金、権限、データの取り扱いルールが適用されます。下書きの依頼は、送信、公開、インストール、アカウント接続、ファイル変更の許可にはなりません。

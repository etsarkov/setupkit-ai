# SetupKit

[English](README.md) · [Español](README.es.md) · [Português (Brasil)](README.pt.md) · [日本語](README.ja.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · Русский · [简体中文](README.zh.md)

Помогите ИИ понять, как вы работаете. Бесплатный файл с инструкциями, по которым ваш ИИ-ассистент поможет составить правила работы и приступить к реальной задаче.

## Как начать

1. Скопируйте [стартовый промпт](START_PROMPT.txt).
2. Вставьте его в свой чат с ИИ и отправьте. Попросите вести разговор на русском языке.
3. Ответьте на вопросы, которые относятся к вашей задаче, и выберите задачу для совместной работы.

Можно начать в текущем чате. Расскажите ассистенту, каким инструментом и как вы пользуетесь. Если для задачи нужен дополнительный доступ, сначала уточните возможности чата. Можно продолжить вручную, отложить этот шаг или выбрать другой режим работы. Установка приложения сама по себе не гарантирует наличие нужных инструментов.

## Текущая версия

[Полный текст руководства](STARTER.md) — версия `0.16.3` от `2026-10-17`. Ассистент должен задавать вопросы по делу, объяснять, зачем они нужны, и использовать уже полученные ответы.

Если источник не удаётся прочитать, следуйте [инструкции по передаче полного текста](docs/getting-started.md#if-the-guide-cannot-be-read). Недостающий текст нужно запросить, а не придумывать. В разделе [«Совместимость и ограничения»](docs/compatibility.md) описано, что проверено, а что нет. Эти справочные документы и основное руководство доступны на английском языке.

## Скиллы

- [Clarify](skills/setupkit-clarify/README.ru.md): задаёт вопросы по существу, чтобы уточнить задачу перед началом работы.
- [Fact Check](skills/setupkit-fact-check/README.ru.md): проверяет утверждения, подтверждающие данные и требования к медиаматериалам перед публикацией.

Порядок установки обоих скиллов — в [общей инструкции установки](INSTALL.ru.md). Сначала проверьте существующие папки скиллов. Для первой пробы используйте новый пустой тестовый проект.

```bash
npx skills add etsarkov/setupkit-ai \
  --skill setupkit-clarify \
  --skill setupkit-fact-check
```

Выберите ассистента и установку в текущий проект; перед подтверждением проверьте целевые пути. npx запускает установщик. Ограничения совместимости и инструкции для отдельного скилла — в [общем разделе скиллов](skills/README.ru.md).

## Ваша работа остаётся у вас

Аккаунт SetupKit не нужен. SetupKit не получает ответы, которые вы даёте своему ассистенту. Стоимость использования, права доступа и правила обработки данных зависят от выбранного ассистента. Просьба подготовить черновик не разрешает отправку, публикацию, установку, подключение аккаунта или изменение файлов.

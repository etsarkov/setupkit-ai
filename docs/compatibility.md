# Compatibility and limits

Edition 0.17 has been exercised in selected local Codex sessions with GPT-6 Astra at xhigh using fictional data. These checks cover selected-material intake, a bounded project overview, skipping questions, continuation and the two optional skill recommendations/application paths. They do not certify every scenario or assistant. Checks of earlier editions in other assistants are historical evidence, not verification of this edition. Claude, Gemini and Perplexity have not been verified for the new 0.17 behavior. Assistant capabilities vary by application, account, plan and provider updates.

| Work mode | Useful starting point | Limit |
|---|---|---|
| Browser chat | Supply text and review a draft | URL reads, attachments, file access and other tools depend on the actual chat |
| Cloud work | Permitted scripts and remote files | Does not imply access to original local files or your signed-in browser |
| Desktop chat | Features the application actually provides | Installation alone does not provide an executor or filesystem permission |
| Local work | Explicitly scoped original-file and tool access | Writes and external actions remain permission-bound |

The guide is plain Markdown, not an installed skill or a technical approval control. Uploaded copies are not live synchronization. A continuation summary does not confer permissions. If access is denied or missing, preserve the existing work and ask for the minimum selected input instead of recreating a setup.

The guide asks your assistant to distinguish preparation, approval, an actual file write and readback. It cannot enforce permissions itself. Use only the access controls your actual environment provides; otherwise keep the result as reviewed text for manual use. Saving a profile does not make every future chat read it automatically. The skills have their own [compatibility and installation limits](../skills/README.md).

Edition 0.17.1 adds brief first-run and return greetings in the person’s language. It preserves the question bank and permission boundaries; the greeting does not add automatic memory, file access, or support for additional assistants.

曖昧な依頼を、作業に進める明確なブリーフにします。

## 使う場面

未回答の質問によって範囲、費用、リスク、成功の基準が変わり得るときにClarifyを使います。既存の文脈を活用し、重要な不足点だけを尋ね、続行に十分な情報がそろったら質問を終えます。

結果には、確定した範囲、受け入れた前提、後回しにした質問、次の手順がまとまります。

## インストール

まずスキルの指示を読んでください。初回は新しい空のテスト用プロジェクトを使います。コマンドを実行する前に、対象の場所とプロジェクト内の共有先に同名のスキルフォルダーがないか確認し、更新は別途判断してください。詳しくは[共通インストールガイド](../../INSTALL.ja.md)を参照してください。

```bash
npx skills add etsarkov/setupkit-ai --skill setupkit-clarify
```

対象のアシスタントとプロジェクト単位の範囲を選びます。確定する前に、事前選択された項目、配置先、最終確認画面を確認してください。一部のアシスタントは.agents/skillsを共有するため、同じプロジェクトの別のアシスタントも、そこに置いたファイルを検出する場合があります。

npxはインストーラーをダウンロードして実行します。検証したバージョンと方式、および互換性の制限は共通のインストールガイドを参照してください。

## 使用例

説明用の例であり、実行記録ではありません。質問は、文脈に回答がない場合にだけ行います。

### 週次レポートを自動化する

**依頼例:**

```text
setupkit-clarifyを使ってください。週次レポートに時間がかかりすぎています。何を自動化するか決めるのを手伝ってください。
```

**質問の例:**

- レポートのデータはどこから来ますか？
- 誰がレポートを使い、どの判断に役立てる必要がありますか？
- どの手順を自動化でき、どこにあなたの確認が必要ですか？

**想定される結果:** 入力、役立つ出力、自動化する手順、人が確認する箇所を定めた流れを作ります。このブリーフは、実装やレポートの送信を許可するものではありません。

### 製品公開の投稿を整理する

**依頼例:**

```text
setupkit-clarifyを使ってください。製品の公開を告知したいです。書き始める前に投稿の内容を整理するのを手伝ってください。
```

**質問の例:**

- 誰に読んでほしく、何を理解してほしいですか？
- 一番伝えたいことは何ですか？
- どの結果や製品の主張を裏付けられ、どのような反応を望みますか？

**想定される結果:** 読者、作者の主張、裏付けのある内容、期待する反応を含む投稿のブリーフを作ります。

## 制限

使用例の質問は説明用です。Clarifyは固定の質問票を強制せず、すでにある回答を再び求めません。単純で十分に明確な依頼なら、追加の質問なしで進められます。

スキルには、利用するアシスタントの権限と承認ルールが引き続き適用されます。アカウントへのアクセスを付与したり、支出、送信、インストール、公開を許可したりするものではありません。

選んだアシスタントと共有する権利のある素材だけを使ってください。機密情報や個人情報を渡す前に、その環境のデータ取り扱い条件を確認してください。

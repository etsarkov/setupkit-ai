在发布前核查事实性陈述及其证据。

## 适用场景

当公开文本已准备好进行事实核查，或你明确要求验证某项陈述时，使用 Fact Check。它区分事实、个人经历、观点与假设，核查可用证据，并返回简明的陈述清单。

结论为 PASS、PASS WITH EDITS 或 BLOCK。关键陈述缺乏支持，或适用的重要媒体素材要求仍未解决时，结论为 BLOCK。

## 安装

请先阅读技能说明。首次尝试请使用新的空白测试项目。运行命令前，检查目标目录和项目共享位置是否已有同名技能文件夹；任何更新都应单独决定。详见[通用安装指南](../../INSTALL.zh.md)。

```bash
npx skills add etsarkov/setupkit-ai --skill setupkit-fact-check
```

选择目标助手，并将安装范围设为当前项目。确认前，请检查预选项、目标路径和最终摘要。部分助手共用 .agents/skills；同一项目中的其他助手也可能发现放在这里的文件。

npx会下载并运行安装程序。已验证的版本、安装方式和兼容性限制见通用安装指南。

## 示例

来源片段和数据均为虚构，不构成关于真实公司、实测结果或图片权利的陈述。

### 保留引述的原意

**待核查材料:**

```text
使用 setupkit-fact-check。虚构来源片段：“我们正在考虑于六月发布。”草稿：“该公司已发布产品。”
```

**示意结果:** 指出未来的可能发布被改成了已经发生的事件。改为忠于来源并注明出处的表述，例如“该公司表示，正在考虑于六月发布”。将最终引述与提供的来源逐一核对。

### 核查百分比

**待核查材料:**

```text
使用 setupkit-fact-check。提供的虚构数据：之前每 100 次访问有 10 次转化，之后每 100 次有 12 次。草稿：“转化率提高了 20 个百分点。”
```

**示意结果:** 改为“转化率从 10% 上升至 12%：提高 2 个百分点，相对增幅为 20%”。核对修正后，此算术示例的结论为 PASS WITH EDITS；这些数字不证明真实测量、统计显著性或因果关系。

### 核查照片来源

**待核查材料:**

```text
使用 setupkit-fact-check。帖子附有一张从网上找到的照片，作者、原始来源和此次用途的使用许可均不明。
```

**示意结果:** 记录缺失的来源和使用许可。在适用的重要媒体素材要求仍未解决时，结论为 BLOCK。要求提供来源和许可，或更换为有证据支持预定用途的素材。

## 限制

核查取决于助手能够使用的来源和工具。会随时间变化的事实需要核查最新信息。PASS 评估的是已核查的措辞和证据；它不代表获准发布，也不能在需要时替代专业建议。

技能仍受所选助手的权限和审批规则约束。它们不授予账户访问权，也不授权支出、发送、安装或发布。

只向所选助手提供你有权分享的材料。提供机密信息或个人信息前，请查阅该环境的数据处理条款。

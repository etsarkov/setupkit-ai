# SetupKit Fact Check

公開前に、主張とそれを裏付ける根拠を確認します。

## 使う場面

公開用の文章が事実確認に進める段階になったとき、または明示的に主張を確認したいときにFact Checkを使います。事実、個人の経験、意見、仮説を区別し、利用できる根拠を調べ、簡潔な主張一覧を返します。

判定はPASS、PASS WITH EDITS、BLOCKのいずれかです。中心となる主張に裏付けがない場合や、メディア素材の重要な要件が未解決の場合はBLOCKになります。

## インストール

まずスキルの指示を読んでください。初回は新しい空のテスト用プロジェクトを使います。コマンドを実行する前に、対象の場所とプロジェクト内の共有先に同名のスキルフォルダーがないか確認し、更新は別途判断してください。詳しくは[共通インストールガイド](../../INSTALL.ja.md)を参照してください。

```bash
npx skills add etsarkov/setupkit-ai --skill setupkit-fact-check
```

対象のアシスタントとプロジェクト単位の範囲を選びます。確定する前に、事前選択された項目、配置先、最終確認画面を確認してください。一部のアシスタントは.agents/skillsを共有するため、同じプロジェクトの別のアシスタントも、そこに置いたファイルを検出する場合があります。

npxはインストーラーをダウンロードして実行します。検証したバージョンと方式、および互換性の制限は共通のインストールガイドを参照してください。

## 使用例

情報源の抜粋とデータは架空のものです。実在企業、実測結果、画像の権利について主張するものではありません。

### 引用の意味を保つ

**確認する素材:**

```text
setupkit-fact-checkを使ってください。架空の情報源の抜粋：「6月の公開を検討しています」。下書き：「同社は製品を公開しました」。
```

**想定される結果:** 将来の可能性が完了した出来事に変わっていると指摘します。「同社は6月の公開を検討していると述べています」など、情報源に忠実で出所を示した表現に直します。最終的な引用は提供された情報源と照合します。

### 割合を確認する

**確認する素材:**

```text
setupkit-fact-checkを使ってください。架空の提供データ：変更前は100回の訪問で10件のコンバージョン、変更後は100回で12件。下書き：「コンバージョン率が20パーセントポイント上昇しました」。
```

**想定される結果:** 「コンバージョン率は10%から12%に上昇しました。差は2パーセントポイント、相対増加率は20%です」に修正します。修正を確認した後、この計算例の判定はPASS WITH EDITSです。この数値は実測、統計的有意性、因果関係を証明しません。

### 写真の出所を確認する

**確認する素材:**

```text
setupkit-fact-checkを使ってください。投稿にインターネットで見つけた写真を使っています。作者、元の情報源、この用途での使用許可は不明です。
```

**想定される結果:** 出所と使用許可が不足していることを記録します。適用されるメディア素材の重要な要件が未解決の間はBLOCKです。出所と許可を求めるか、予定する用途での使用を裏付けられる素材に差し替えます。

## 制限

確認できる範囲は、アシスタントが使える情報源とツールに依存します。時間とともに変わる事実は、現在の情報での確認が必要です。PASSは確認した表現と根拠の評価であり、公開の許可や、必要な専門家の助言の代わりにはなりません。

スキルには、利用するアシスタントの権限と承認ルールが引き続き適用されます。アカウントへのアクセスを付与したり、支出、送信、インストール、公開を許可したりするものではありません。

選んだアシスタントと共有する権利のある素材だけを使ってください。機密情報や個人情報を渡す前に、その環境のデータ取り扱い条件を確認してください。
